# Definition of Done

A V1 feature is done when:

- requirements are implemented
- authorization is enforced
- tenant isolation is tested
- validation and error handling exist
- audit requirements are satisfied
- database migrations are reversible/controlled
- automated tests cover critical behavior
- API contract is documented
- UI is responsive where applicable
- accessibility is considered
- observability is present for important workflows
- background jobs are idempotent
- security/privacy implications are reviewed
- acceptance criteria pass in a staging environment
