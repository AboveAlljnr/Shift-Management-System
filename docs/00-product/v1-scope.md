# V1 Scope

## Required at launch

The launch product includes company/workforce administration, scheduling, conflict validation, attendance, leave, activities, documents, notifications, reporting, billing, Super Admin, security/privacy, auditing, and the responsive PWA experience.

## Deferred

The following are V1.x/future architecture targets rather than V1 launch blockers:

- Public API
- Webhooks
- External calendar integrations
- Attendance-device integrations
- Payroll integrations
- Advanced workforce forecasting
- Native mobile applications
- Advanced white-labeling
- Advanced automation and deeper AI optimization

## Scope rule

Do not add infrastructure or product complexity solely for deferred features unless the V1 design would otherwise create an expensive migration later.
